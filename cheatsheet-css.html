Cheatsheet

CSS3

Selectores, maquetación y responsive: la referencia rápida para dar estilo a tu portfolio.

Selectores

Cómo elegir a qué elementos se aplica una regla. 

/* Etiqueta */
p { line-height: 1.6; }

/* Clase (se puede repetir) */
.card { border-radius: 12px; }

/* Id (único) */
#header { position: sticky; }

/* Descendiente: cualquier h3 dentro de .card */
.card h3 { margin-bottom: 0.5rem; }

/* Hijo directo */
nav > ul { display: flex; }

/* Varios a la vez */
h1, h2, h3 { font-family: "Roboto", sans-serif; }

/* Estados y posición */
a:hover { text-decoration: underline; }
li:first-child { font-weight: bold; }
li:nth-child(even) { background: #f2f2f2; }

/* Atributo */
a[target="_blank"] { color: teal; }

/* Pseudoelemento */
.titulo::after { content: " →"; }
  • Prioridad de mayor a menor: estilo en línea, id, clase, etiqueta.
  • Si dos reglas tienen la misma prioridad, gana la que está más abajo.
  • Para estilos, usa clases: los id pesan demasiado y no se pueden repetir.

Modelo de caja

Todo elemento es una caja: contenido, padding, borde y margin. 

*,
*::before,
*::after {
  box-sizing: border-box;
}

.card {
  width: 300px;
  padding: 1rem;            /* espacio por dentro */
  border: 1px solid #ccc;   /* borde */
  margin: 0 auto 1.5rem;    /* espacio por fuera */
}

/* Atajos: arriba abajo | izquierda derecha */
.boton { padding: 0.5rem 1.25rem; }

/* Un valor por lado: arriba derecha abajo izquierda */
.caja { margin: 10px 20px 10px 20px; }
  • Con box-sizing: border-box, el width incluye padding y borde.
  • margin: 0 auto centra horizontalmente un bloque con ancho definido.
  • Con dos valores: el primero es arriba/abajo, el segundo izquierda/derecha.

Unidades de medida

Cuándo usar cada una.

html { font-size: 100%; }          /* 16px por defecto */

h1 { font-size: 2.5rem; }           /* rem: relativa al html */
.icono { width: 1.5em; }            /* em: relativa al padre */
.card { width: 50%; }               /* %: relativa al contenedor */
.hero { min-height: 100vh; }        /* vh: alto de la pantalla */
.contenedor { max-width: 70ch; }    /* ch: ancho de un carácter */

/* Tamaños que se adaptan solos */
h1 { font-size: clamp(2rem, 5vw, 3.5rem); }
.contenedor { width: min(90%, 1100px); margin-inline: auto; }
  • rem para tipografías y espacios: respeta el tamaño que elige la persona.
  • px para detalles finos, como un borde de 1px.
  • clamp(mínimo, ideal, máximo) evita muchos media queries.

Colores y variables

Define la paleta una vez y úsala en todo el sitio. 

/* Variables en :root, disponibles en toda la página */
:root {
  --color-fondo: #0f1a14;
  --color-texto: #e8efe9;
  --color-acento: #4caf7a;
  --radio: 12px;
  --sombra: 0 8px 20px rgba(0, 0, 0, 0.25);
}

body {
  background-color: var(--color-fondo);
  color: var(--color-texto);
}

.boton {
  background-color: var(--color-acento);
  border-radius: var(--radio);
  box-shadow: var(--sombra);
}

/* Formatos de color */
.ejemplo-1 { color: #4caf7a; }
.ejemplo-2 { color: rgb(76 175 122); }
.ejemplo-3 { color: hsl(147 40% 49%); }
.ejemplo-4 { color: rgb(0 0 0 / 50%); }  /* con transparencia */
  • Las variables se declaran con --nombre y se usan con var(--nombre).
  • Cambiar una variable cambia todo el sitio: perfecto para el modo oscuro.
  • Si usas un valor de color más de dos veces, conviértelo en variable.

Flexbox

Para colocar elementos en una sola dimensión: fila o columna. 

/* El contenedor */
.menu {
  display: flex;
  flex-direction: row;            /* row | column */
  justify-content: space-between; /* eje principal */
  align-items: center;            /* eje cruzado */
  flex-wrap: wrap;                /* permite pasar a otra línea */
  gap: 1rem;                      /* separación entre hijos */
}

/* Los hijos */
.menu-item {
  flex: 1 1 200px;  /* crece | se encoge | tamaño base */
}

/* Centrar algo en la pantalla */
.centro {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 100vh;
}
  • justify-content actúa en el eje principal; align-items, en el cruzado.
  • Si cambias a flex-direction: column, los dos ejes se intercambian.
  • gap es mucho más cómodo que poner márgenes a cada hijo.

CSS Grid

Para maquetar en dos dimensiones: filas y columnas. 

/* Tarjetas que se reparten solas */
.lista {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 1.5rem;
}

/* Tres columnas fijas */
.tres-columnas {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}

/* Un elemento que ocupa dos columnas */
.destacada {
  grid-column: span 2;
}

/* Maquetación con áreas con nombre */
.pagina {
  display: grid;
  grid-template-areas:
    "cabecera cabecera"
    "menu     contenido"
    "pie      pie";
}
.cabecera { grid-area: cabecera; }
  • 1fr significa «una parte del espacio libre».
  • repeat(auto-fit, minmax(220px, 1fr)) crea un diseño responsive sin media queries.
  • Flexbox para alinear una fila de cosas; Grid para organizar una cuadrícula.

Posición

Sticky, absolute y compañía.

/* Se queda fijo al hacer scroll, dentro de su contenedor */
.cheatsheet-nav {
  position: sticky;
  top: 0;
  z-index: 10;
}

/* El padre es la referencia... */
.card {
  position: relative;
}

/* ...y el hijo se coloca respecto a él */
.card .etiqueta {
  position: absolute;
  top: 0.5rem;
  right: 0.5rem;
}

/* Fijo respecto a la ventana */
.boton-subir {
  position: fixed;
  bottom: 1rem;
  right: 1rem;
}
  • sticky necesita un top (o similar) para saber dónde pegarse.
  • No funciona si un elemento padre tiene overflow: hidden.
  • absolute se coloca respecto al antecesor más cercano con position distinto de static.

Responsive design

Primero el móvil, luego se amplía.

/* 1. Estilos base: pensados para móvil */
.cheatsheet-nav {
  display: none;
}

.lista {
  display: grid;
  grid-template-columns: 1fr;
}

/* 2. Tablet y escritorio: se añaden mejoras */
@media (min-width: 768px) {
  .cheatsheet-nav {
    display: block;
  }

  .lista {
    grid-template-columns: repeat(2, 1fr);
  }
}

@media (min-width: 1100px) {
  .lista {
    grid-template-columns: repeat(3, 1fr);
  }
}

/* Imágenes que nunca se salen de su caja */
img {
  max-width: 100%;
  height: auto;
}
  • «Mobile first»: escribe lo básico fuera y amplía con min-width.
  • Puntos de corte habituales: 768px (tablet) y 1100px (escritorio).
  • Para ocultar la navegación lateral en móvil: display: none por defecto.
  • Prueba reduciendo la ventana o con las herramientas del navegador (F12).

Transiciones y animaciones

Efecto hover en tarjetas y animaciones con keyframes. 

/* Transición: cambia suavemente entre dos estados */
.card {
  transition: transform 0.3s ease, box-shadow 0.3s ease;
}

.card:hover {
  transform: translateY(-6px);
  box-shadow: 0 12px 25px rgba(0, 0, 0, 0.25);
}

/* Animación con keyframes */
@keyframes latido {
  0%, 100% { transform: scale(1); }
  50%      { transform: scale(1.1); }
}

.corazon {
  animation: latido 1.2s ease-in-out infinite;
}

/* Respeta a quien prefiere menos movimiento */
@media (prefers-reduced-motion: reduce) {
  * {
    animation: none;
    transition: none;
  }
}
  • Anima transform y opacity: son baratas para el navegador.
  • La transition se escribe en el estado normal, no en el :hover.
  • prefers-reduced-motion evita mareos a personas sensibles al movimiento.

Modo claro / oscuro con variables

La paleta cambia en un solo sitio, y se combina con localStorage. 

/* Por defecto: modo oscuro */
:root {
  --color-fondo: #0f1a14;
  --color-texto: #e8efe9;
  --color-tarjeta: #18271e;
}

/* Cuando JavaScript añade esta clase, se sobrescribe la paleta */
.lightModeActive {
  --color-fondo: #eef6ef;
  --color-texto: #1b2a20;
  --color-tarjeta: #ffffff;
}

body {
  background-color: var(--color-fondo);
  color: var(--color-texto);
  transition: background-color 0.3s ease, color 0.3s ease;
}

.card {
  background-color: var(--color-tarjeta);
}
  • Todos los colores del sitio deben salir de variables, o el modo claro dejará zonas sin cambiar.
  • JavaScript solo añade o quita la clase; el CSS hace el resto.
  • La clase se guarda en localStorage para que no se pierda al recargar (mira la cheatsheet de JavaScript).

Checklist de CSS

  • reset.css cargado antes que styles.css.
  • box-sizing: border-box aplicado a todo.
  • Colores, radios y sombras guardados como variables.
  • Estilos base para móvil y mejoras con min-width.
  • Imágenes con max-width: 100%.
  • Estados :hover y :focus-visible en enlaces y botones.
  • Probado en modo claro y modo oscuro.
