JavaScript

De las variables al DOM, pasando por módulos y localStorage: lo que usas cada día para dar vida a una web.

Variables y tipos

const por defecto, let solo si el valor va a cambiar. 

const nombre = "Víctor";        // string
let intentos = 0;                // number
const activo = true;             // boolean
const vacio = null;              // sin valor a propósito
let sinAsignar;                  // undefined

intentos += 1;                   // ahora vale 1

console.log(typeof nombre);      // "string"

// Template string: mezcla texto y variables
const saludo = `Hola, soy ${nombre} y llevo ${intentos} intento`;
  • Usa const siempre que puedas; no obliga a que el valor sea inmutable en objetos y arrays, pero no se puede reasignar.
  • Los template strings van entre comillas invertidas y usan ${}.
  • console.log() es tu mejor aliado para depurar.

Condicionales y operadores

Tomar decisiones en el código.

const nota = 7;

if (nota >= 9) {
  console.log("Sobresaliente");
} else if (nota >= 5) {
  console.log("Aprobado");
} else {
  console.log("Suspenso");
}

// Operador ternario
const estado = nota >= 5 ? "Aprobado" : "Suspenso";

// Comparar: usa SIEMPRE ===
console.log(5 === "5");   // false (distinto tipo)
console.log(5 == "5");    // true  (evítalo)

// Lógicos
if (nota >= 5 && nota < 9) { /* las dos se cumplen */ }
if (nota < 5 || nota > 10) { /* se cumple al menos una */ }
if (!activo) { /* si NO es verdadero */ }

// Valor por defecto
const tema = localStorage.getItem("theme") ?? "dark";
  • === compara valor y tipo; = asigna, no compara.
  • Valores «falsy»: false, 0, "", null, undefined y NaN.
  • ?? solo usa el valor por defecto si lo de la izquierda es null o undefined.

Funciones

Declaradas, de flecha y con parámetros por defecto. 

// Declarada
function sumar(a, b) {
  return a + b;
}

// Flecha, con llaves: necesita return
const restar = (a, b) => {
  return a - b;
};

// Flecha, sin llaves: devuelve directamente
const doble = (n) => n * 2;

// Valor por defecto
const saludar = (nombre = "visitante") => `Hola, ${nombre}`;

console.log(sumar(2, 3));   // 5
console.log(saludar());     // "Hola, visitante"
  • Sin return, una función devuelve undefined.
  • Una arrow function sin llaves devuelve el resultado de forma implícita.
  • Los paréntesis () son los que ejecutan la función: main() la llama, main no.

Arrays y sus métodos

map, filter y find son la base del renderizado dinámico. 

const skills = ["HTML", "CSS", "JavaScript", "Git"];

skills.push("React");        // añade al final
console.log(skills.length);  // 5
console.log(skills[0]);      // "HTML"

// Recorrer
skills.forEach((skill) => console.log(skill));

// map: devuelve un array nuevo transformado
const mayusculas = skills.map((skill) => skill.toUpperCase());

// filter: se queda solo con lo que cumple la condición
const cortas = skills.filter((skill) => skill.length <= 3);

// find: devuelve el primero que cumple (o undefined)
const git = skills.find((skill) => skill === "Git");

// includes: ¿está dentro?
console.log(skills.includes("CSS"));   // true

// reduce: junta todo en un solo valor
const total = [10, 20, 30].reduce((acc, n) => acc + n, 0);   // 60
  • map devuelve un array de la misma longitud; filter, uno igual o más corto.
  • Iterar es recorrer los elementos uno a uno, aplicando algo a cada uno.
  • Se pueden encadenar: skills.filter(...).map(...).

Objetos

Datos agrupados en pares clave-valor.

const skill = {
  name: "HTML5",
  level: "dominada",
  tags: ["web", "marcado"],
  describir() {
    return `${this.name} (${this.level})`;
  },
};

// Leer y modificar
console.log(skill.name);        // punto
console.log(skill["level"]);    // corchetes
skill.level = "avanzada";

// Desestructurar
const { name, level } = skill;

// Copiar y modificar sin tocar el original
const copia = { ...skill, level: "experto" };

// Claves y valores
console.log(Object.keys(skill));
console.log(skill.describir());
  • Dentro de un método, this es el objeto que lo llama.
  • Una arrow function no tiene su propio this: en métodos usa la forma normal.
  • Un array de objetos es el formato de tus ficheros de datos (skills.js, cheatsheets.js).

El DOM

Seleccionar elementos y cambiar la página desde JavaScript. 

// Seleccionar
const titulo = document.querySelector("#titulo");       // uno
const tarjetas = document.querySelectorAll(".card");    // todos

// Cambiar contenido y clases
titulo.textContent = "Nuevo título";
titulo.classList.add("activo");
titulo.classList.remove("activo");
titulo.classList.toggle("activo");

// Pintar una lista desde un array
const contenedor = document.querySelector("#lista");
contenedor.innerHTML = skills
  .map((skill) => `<li>${skill}</li>`)
  .join("");

// Crear un elemento a mano
const parrafo = document.createElement("p");
parrafo.textContent = "Creado con JavaScript";
contenedor.append(parrafo);

// Evitar el error típico
if (!contenedor) return;
  • querySelector devuelve null si no encuentra nada: el error «Cannot set properties of null» viene de ahí.
  • innerHTML reemplaza todo el contenido del elemento, incluidos los títulos que hubiera dentro.
  • El .join("") quita las comas que aparecen al convertir el array en texto.
  • Para un texto simple usa textContent: es más seguro que innerHTML.

Eventos

Reaccionar a lo que hace la persona: clics, envíos, teclas. 

// Clic en un botón
const boton = document.querySelector("#boton-tema");
boton.addEventListener("click", () => {
  document.body.classList.toggle("lightModeActive");
});

// Varios elementos: un listener en cada uno
const tabs = document.querySelectorAll(".tab");
tabs.forEach((tab) => {
  tab.addEventListener("click", (event) => {
    const id = event.currentTarget.dataset.tab;
    console.log("Pestaña pulsada:", id);
  });
});

// Formulario: evitar que recargue la página
const form = document.querySelector("#contacto");
form.addEventListener("submit", (event) => {
  event.preventDefault();
  console.log("Formulario enviado");
});
  • addEventListener("evento", función) recibe una función, no la ejecuta.
  • event.currentTarget es el elemento al que pusiste el listener.
  • Con data-tab="docs" en el HTML, lees dataset.tab en JavaScript.
  • Para un sistema de pestañas: al pulsar, quita la clase active a todas y se la pones a la elegida.

Módulos: import y export

Un archivo, una responsabilidad.

// js/data/skills.js  → export nombrado (con llaves al importar)
export const skills = [
  { name: "HTML5", level: "dominada" },
];

// js/utils/skillsList.js  → export default (sin llaves al importar)
import { skills } from "../data/skills.js";

export default function skillsList() {
  const contenedor = document.querySelector("#skills-list");
  if (!contenedor) return;
  contenedor.innerHTML = skills
    .map((skill) => `<article>${skill.name}</article>`)
    .join("");
}

// js/main.js
import skillsList from "./utils/skillsList.js";

skillsList();
  • Export nombrado → import { nombre }. Export default → import nombre.
  • En los imports del navegador, la extensión .js es obligatoria.
  • El HTML debe cargar el script con type="module".
  • Los módulos no funcionan abriendo el archivo con doble clic: usa Live Server.

localStorage

Guardar datos en el navegador para que no se pierdan al recargar. 

// Guardar (clave, valor): solo guarda texto
localStorage.setItem("theme", "light");

// Leer: devuelve null si no existe
const tema = localStorage.getItem("theme");

// Borrar
localStorage.removeItem("theme");

// Objetos y arrays: convertir a texto y volver
const preferencias = { theme: "dark", idioma: "es" };
localStorage.setItem("prefs", JSON.stringify(preferencias));

const guardadas = JSON.parse(localStorage.getItem("prefs"));

// Patrón del modo oscuro
const temaGuardado = localStorage.getItem("theme");
if (temaGuardado === "light") {
  document.body.classList.add("lightModeActive");
}
  • Solo guarda texto: para objetos usa JSON.stringify y JSON.parse.
  • Al cargar la página, lee el valor guardado y aplica la clase antes de que el usuario toque nada.
  • Puedes ver y borrar lo guardado en F12 → Application → Local Storage.
  • No guardes contraseñas ni datos sensibles: cualquiera puede leerlo.

Errores típicos y cómo leerlos

  • Cannot set properties of null: el selector no encontró el elemento (revisa el id y la página).
  • X is not a function: falta un export/import, o lo llamas sin los paréntesis correctos.
  • Failed to resolve module specifier: ruta mal escrita o falta la extensión .js.
  • No pasa nada y no hay error: ¿llamaste a la función en main.js?
  • Cambios que no se ven: guarda el archivo y reinicia Live Server o recarga con Ctrl + Shift + R.
